# 🎙️ AudioRecorderApp

> 📲 Умное приложение для записи и отправки аудио с таймером и авто-загрузкой  
> Разработано на **React Native + Expo**

---

## ⚙️ Описание

AudioRecorderApp — это мобильное приложение, которое позволяет:

- Записывать аудио с микрофона
- Устанавливать таймер для автоостановки
- Загружать аудиофайлы на указанный сервер
- Повторно пытаться отправить файл при сетевых сбоях
- Проверять доступность API сервера
- Предоставлять пользователю понятные уведомления и визуальные индикаторы

---

## 🚀 Основной функционал

- 🎤 **Запись звука**  
  Простое управление записью с устройства

- ⏱ **Таймер автоостановки**  
  Установка длительности записи по часам и минутам

- ☁️ **Загрузка аудио на сервер**  
  Указание конечной точки загрузки с логикой повтора

- 📶 **Проверка сети**  
  Запрет на запись/загрузку при отсутствии интернета

- 🧠 **Механизм повтора**  
  Повторные попытки отправки с экспоненциальной задержкой

- 🛡 **Обработка ошибок**  
  Поддержка всех кейсов: от отказа в разрешении до недоступного API

---

## 🧩 Управление состоянием

- `fileName` — имя файла
- `serverUrl` — URL сервера
- `uploadEndpoint` — финальный путь загрузки
- `isRecording`, `isConnected`, `uploading`
- `timerId`, `hours`, `minutes`
- `recordingRef` — ссылка на текущую сессию записи (через `useRef`)

---

## 🧠 Основные функции

| Функция              | Описание |
|----------------------|----------|
| `startRecording()`   | Запуск записи, проверка сети/разрешений |
| `stopRecording()`    | Остановка, выгрузка, очистка таймера |
| `startTimer()`       | Автоостановка записи |
| `attemptUploadFile()`| Повторная отправка при ошибках |
| `uploadFile()`       | Отправка аудиофайла через Axios |
| `checkApi()`         | Проверка сервера через GET-запрос |
| `handleSaveServerUrl()` | Сохранение адреса сервера |

---

## 🖥 Компоненты интерфейса

- 📝 `TextInput` — ввод URL сервера, имени файла, таймера
- 🔘 `Button` — управление записью и загрузкой
- 🔄 `ActivityIndicator` — статус загрузки
